# Check a refused or incomplete run

Start with `pymicroglia doctor` and `pymicroglia describe ACTION`.
Pending tracking and missing learning dependencies are different cases.
Install the named extra for an unavailable method; no fallback changes science.

Check saved table names, recording identity, metric groups and sample mapping.
Fresh-fit figures need observation and analysis settings. Saved-result figures
need their exact figure-plan item and unchanged completed evidence.

A changed-hash error is a provenance failure. Preserve the old result and
create a new version from intended inputs; do not edit hashes to force reuse.
Assigning a 24-hour period does not resolve unsupported evidence.

Step outcomes and linked reports explain unavailable results. Disabled questions
and untestable traces remain visible. If Windows retries report a persistent
file lock, close the application holding that destination.

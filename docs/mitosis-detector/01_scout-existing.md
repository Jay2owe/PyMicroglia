# 01 scout-existing

Use `implementation-scout` before building. Compare, for the question "can it take our label stacks and call divisions?":

- btrack (Bayesian tracker with division hypotheses)
- Trackastra (learned association with divisions)
- TrackMate with a division detector add-on, and Ultrack
- DeepCell tracking

For each: licence, last release, whether it accepts bioluminescence or weak-signal label stacks, and whether it can run on saved masks rather than re-tracking. Report each as use as-is, take parts, or build. Do not install anything beyond a disposable environment.

Done when: a table with a recommendation per tool, and a decision on whether stage 03 to 04 reuse any of them.

# Workflows

Task-based guides cross several actions or result interfaces.

| Workflow | Use it when |
|---|---|
| [First analysis](../getting-started/first-analysis.md) | You are starting from an unanalysed time-lapse. |
| [Check a run](../getting-started/check-a-run.md) | A run finished and you need its outputs, record, or equivalent script. |
| [Reanalyse with new parameters](reanalyse-with-new-parameters.md) | You want to change one decision without paying for every earlier stage again. |

More workflow pages can be added here as stable user routes emerge. Individual
operations belong in [Actions](../actions/README.md); complete named analyses
belong in [Pipelines](../pipelines/README.md).
